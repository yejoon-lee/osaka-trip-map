# 오사카 장소 목록

한국어 모바일 단일 열 장소 목록입니다. 기존 77곳을 카테고리별로 묶고, 각 장소에 Google Maps 외부 링크 하나만 제공합니다. 빌드 단계나 런타임 npm 의존성은 없습니다.

## 로컬 실행

```sh
cd osaka-trip-map
python3 -m http.server 8080 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8080`을 엽니다. `places.json`을 fetch하므로 파일 더블클릭 방식은 지원하지 않습니다.

## 테스트

Node.js 22 이상을 사용합니다. 순수 함수 및 실제 데이터 검증:

```sh
node --test tests/core.test.mjs tests/data.test.mjs
```

실제 Chromium 브라우저 테스트를 포함한 전체 검증:

```sh
npm install --prefix .test-tools --no-save --package-lock=false playwright
node .test-tools/node_modules/playwright/cli.js install chromium
node --test tests/*.test.mjs
```

테스트는 로컬 HTTP 서버를 자동으로 시작·종료합니다. 실제 77곳과 카테고리별 개수, 그룹 제목, 검색·지역·카테고리 필터 조합, 초기화, 빈 결과, 안전한 텍스트·링크, 데이터 로딩 오류를 검증합니다. 360×800, 390×844, 844×390, 1440×844에서 가로 넘침 없이 문서 전체가 스크롤되는지, 링크 높이가 44px 이상인지, 지도/타일/외부 리소스 요청과 위치 요청이 없는지도 확인합니다. 스크린샷은 `test-results/list-*.png`에 생성됩니다. 보안·오류 테스트의 응답 주입은 실제 데이터 파일을 변경하지 않습니다.

## 동작과 데이터

- 기본 화면: 음식 39, 카페·디저트 9, 쇼핑 13, 관광 7, 호텔 1, 편의·서비스 8 — 총 77곳.
- 원본 79곳 중 공항과 교토의 2곳은 기존 데이터대로 제외합니다. `places.json`은 변경하지 않았습니다.
- 검색은 이름·원어명·종류·메모·주소·지역·카테고리를 대상으로 합니다.
- 카테고리 버튼의 수는 검색어와 지역 조건을 반영하되 선택된 카테고리 자체는 집계에서 제외합니다. 그룹 제목에는 실제 표시되는 수를 표시합니다.
- 호텔은 다른 장소와 같은 일반 호텔 카테고리입니다. 개인 숙소 표시는 없습니다.
- 고정 헤더, 사이드바, 탭, 내장 지도, 위치 기능, 지도 라이브러리 및 타일 요청이 없습니다. 페이지 전체를 일반 문서처럼 스크롤합니다.
- 각 장소에 이름·종류·지역·원어명·메모·주소를 표시하며 빈 정보는 생략합니다. 외부 이동은 단일 `Google Maps에서 보기` 링크로 새 탭에서 열립니다. 별도 길찾기 링크는 없습니다.
- 출처 링크가 없거나 안전하지 않으면 이름·좌표 기반 Google Maps 검색 링크를 생성합니다.
- 출처는 저장 목록의 스냅샷입니다. 가격·재고·영업 정보는 실시간이 아니며 원본 목록 변경은 자동 동기화되지 않습니다.
- 데이터 로딩 실패 시 연결 확인 및 새로고침 안내를 표시합니다.

## 파일

`index.html`, `styles.css`, `app.js`는 UI, `core.mjs`는 순수 필터·집계·Google Maps 링크 함수입니다. `places.json`은 장소 원본 데이터입니다. `.nojekyll`은 정적 호스팅용입니다. 스타일과 앱의 캐시 버전은 `?v=3`입니다.

배포 시 테스트 도구 `.test-tools/`와 테스트 증거 파일은 제외하세요. GitHub Pages는 `main` 브랜치 루트에서 정적 파일을 제공합니다.
