# 오사카 장소 목록

한국어 모바일 단일 열 장소 목록입니다. 원본 77곳을 카테고리별로 보거나, 사용자가 직접 확인한 위치에서 가까운 순으로 볼 수 있습니다. 내장 지도·빌드 단계·런타임 npm 의존성은 없습니다.

## 로컬 실행

```sh
cd osaka-trip-map
python3 -m http.server 8080 --bind 127.0.0.1
```

`http://127.0.0.1:8080`에서 엽니다. JSON을 fetch하므로 파일 더블클릭 방식은 지원하지 않습니다. 위치 기능은 HTTPS 또는 localhost에서 사용합니다.

## 테스트

Node.js 22 이상:

```sh
node --test tests/core.test.mjs tests/data.test.mjs
npm install --prefix .test-tools --no-save --package-lock=false playwright
node .test-tools/node_modules/playwright/cli.js install chromium
node --test tests/*.test.mjs
```

브라우저 테스트는 로컬 HTTP 서버와 Chromium을 자동 시작·종료합니다. 실제 77곳, 카테고리 개수, 필터 조합, 초기화, 빈 결과, 안전한 텍스트·링크, 데이터 로딩 실패를 검증합니다. 360×800, 390×844, 844×390, 1440×844의 가로 넘침·문서 스크롤·44px 링크를 확인합니다.

위치 테스트는 **테스트에서만** geolocation 응답을 주입합니다. 기본 진입/가까운 순 선택 시 요청 없음, 명시적 클릭 후 성공, 전역 거리 정렬, 검색·지역·카테고리 조합, 재확인, 삭제, 늦은 응답 무시, 권한 거부·시간 초과·위치 불가·API 미지원, 저장 및 외부 네트워크 요청 없음을 검사합니다. Haversine 순수 함수는 동일 좌표·대칭·경도 1도·대척점·잘못된 좌표·동률 정렬을 검증합니다.

리뷰 테스트는 대표 보충 응답만 주입하며 원본 JSON을 수정하지 않습니다. 확인된 리뷰/미확인 리뷰, 설명, 표본 수·확인일·출처, 안전하지 않은 링크, 보충 파일 누락·오류를 검증합니다. 스크린샷은 `test-results/list-*.png`, `location-390.png`, `reviews-390.png`입니다.

## 목록과 위치

- 기본 카테고리: 음식 39, 카페·디저트 9, 쇼핑 13, 관광 7, 호텔 1, 편의·서비스 8 — 총 77곳. 원본 79곳 중 공항·교토 2곳은 기존대로 제외합니다.
- 검색은 이름·원어명·종류·원본 메모·주소·지역·카테고리 대상입니다. 보충 설명·리뷰는 검색 대상이 아닙니다.
- 카테고리 수는 검색어와 지역을 반영하며 선택 카테고리 자체는 집계에서 제외합니다.
- 기본은 카테고리순. 가까운 순은 **현재 필터 결과 전체**를 거리순으로 정렬하며 카테고리별로 다시 묶지 않습니다. 거리가 같으면 장소 id로 순서를 고정합니다. 좌표 없는 장소는 마지막이며 거리 미확인으로 표시합니다.
- 위치 없이 가까운 순을 선택하면 내 위치 버튼 안내와 기존 카테고리순 목록을 표시합니다. 정렬 선택만으로 권한을 요청하지 않습니다.
- **내 위치 / 위치 새로 확인 클릭에서만** `navigator.geolocation.getCurrentPosition`을 호출합니다. 자동 위치 조회, `watchPosition`, 서버 지오코딩은 없습니다. 요청 옵션은 저전력 우선·12초 제한·기존 캐시 미사용입니다.
- 위치·정확도·확인 시각은 페이지 메모리와 화면에만 존재합니다. localStorage, sessionStorage, 쿠키, IndexedDB, URL에 저장하지 않습니다. 새로고침 시 사라집니다. 위치 지우기는 좌표와 링크를 제거하고 카테고리순으로 복귀하며 진행 중인 요청의 늦은 응답도 무시합니다.
- Google Maps 내 위치 링크는 선택 사항입니다. **링크 클릭 전에는 앱이 좌표를 외부 서버에 전송하지 않습니다.** 브라우저/운영체제의 위치 획득 자체는 사용자의 위치 권한 및 플랫폼 설정을 따릅니다.
- 거리는 Haversine으로 계산한 **직선거리(m/km)**이며 도보 경로·이동 시간·길찾기 결과가 아닙니다. 위치 오차에 따라 정렬도 달라질 수 있습니다.
- 권한 거부·시간 초과·위치 불가·미지원 때도 필터/목록은 동작하며 외부 Safari·Chrome에서 여는 방법을 안내합니다. 재확인 실패 시 이전 위치를 제거합니다.
- 필터 초기화는 검색·지역·카테고리만 초기화하고 위치·정렬은 유지합니다. 위치 삭제는 별도 버튼입니다.
- 호텔은 일반 카테고리입니다. 고정 헤더·사이드바·탭·내장 지도·지도 라이브러리·타일 요청은 없습니다.

## 선택적 리뷰 보충 데이터

`places.json`은 원본 데이터로 유지합니다. 별도 `enrichment.json`은 아래 구조이며 장소 `id`로 연결합니다. 파일이 없거나 요청/JSON 파싱에 실패해도 77곳 목록은 즉시 표시됩니다. 보충 파일을 기다리지 않고 원본 목록을 먼저 렌더링합니다.

```text
{
  "places": {
    "<places.json의 id>": {
      "description": "한국어 장소 설명",
      "reviewSummary": "직접 확인한 리뷰 표본에 근거한 한국어 요약",
      "reviewStatus": "reviewed 또는 unavailable",
      "sampleSize": 0,
      "checkedAt": "YYYY-MM-DD 또는 ISO 시각",
      "sourceUrl": "https://www.google.com/maps?...",
      "rating": null,
      "reviewCount": null
    }
  }
}
```

- 이 구현은 리뷰를 수집하거나 만들어내지 않습니다. 데이터 작성자가 출처를 직접 확인한 경우에만 `reviewed`로 기록해야 합니다.
- 설명·리뷰는 기본 접힌 `상세 / 리뷰`에서 표시합니다. 원본 메모는 **내 저장 메모**로 별도 구분합니다.
- `reviewed`이면서 요약·확인일·안전한 Google Maps 출처가 있으면 `표시된 리뷰 N개 참고`, 확인일, 알려진 평점/전체 리뷰 수 및 출처 링크를 표시합니다. 표본 수가 없으면 `표시된 리뷰 참고 (표본 수 미기록)`으로 표시합니다. 전체 리뷰 수를 표본 수로 오인하지 않습니다.
- `unavailable`, 누락 또는 불완전한 검증 메타데이터는 **Google Maps 리뷰 미확인**으로 표시합니다. 설명이 있으면 그대로 보여주지만 리뷰 요약·평점 등 검증된 리뷰처럼 보이는 정보는 숨깁니다.
- 모든 문자열은 텍스트로 렌더링합니다. 출처는 HTTPS Google Maps 허용 도메인만 링크합니다. 장소 기본 링크는 원본 출처가 안전하지 않으면 이름·좌표 기반 Google Maps 검색으로 대체합니다.
- 원본/보충 정보는 스냅샷이며 가격·재고·영업 정보 및 평점은 실시간이 아닙니다. 방문 전 Google Maps에서 확인하세요.

## 파일과 배포

`index.html`, `styles.css`, `app.js`는 UI, `core.mjs`는 순수 필터·집계·링크·거리 함수입니다. 스타일·앱·core import의 캐시 버전은 `?v=4`입니다. `places.json`과 선택적 `enrichment.json`은 독립 데이터입니다.

`.nojekyll`은 정적 호스팅용입니다. 배포 시 `.test-tools/`, `test-results/`는 제외합니다. GitHub Pages는 `main` 브랜치 루트에서 정적 파일을 제공합니다. 이번 구현은 커밋·배포하지 않습니다.
